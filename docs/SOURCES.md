# Sources

**Owner: Joaquin**

Every medical rule in `knowledge_base/conditions.yaml` must appear here with
where it came from. The test suite fails if any rule has a blank source.

A judge at PDR, CDR, or FDR will ask where our medical logic came from. This
file is the answer.

- Another student
